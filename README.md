# Library Management System

A Java-based Library Management System built using OOP, JDBC, and MySQL.

---

## Features

### Admin
- Add books
- Update book quantity
- Soft delete books
- View all available books
- Manage borrow and return operations

### User
- View available books
- Borrow books
- Return books
- View borrowed books

---

## Technologies Used
- Java (OOP)
- JDBC
- MySQL

---

## Database Tables
- users
- books
- transactions

---

## Key Features Implemented
- Authentication system (Login/Register)
- Role-based access (Admin/User)
- Soft delete implementation (is_deleted)
- Transaction tracking (Borrow / Return)
- User borrowed books history

---

## How to Run
1. Import the project into IntelliJ or Eclipse
2. Create the MySQL database using schema.sql
3. Update database connection settings in DBConnection class
4. Run Main.java
